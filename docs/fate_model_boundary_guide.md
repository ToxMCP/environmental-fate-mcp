# Fate Model Boundary Guide

The public abstraction is not "run a branded fate engine." The public abstraction is "build a release scenario and estimate concentration surfaces."

Adapters may normalize external model outputs into Fate MCP contracts, but model-native payloads are not the public interface.

This boundary does not change for TCM, herbal medicine, or supplement questions. Fate MCP still
publishes concentration outputs only. Medicinal direct-use regimens remain downstream
Direct-Use Exposure MCP territory, while food-mediated herbal or supplement intake remains
Dietary MCP territory.
